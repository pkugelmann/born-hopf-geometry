# Current full source archives — v1.2 website edition

The four original archives are embedded in `docs/data/` as downloadable ZIP files. They are versioned and stored byte-for-byte from the project uploads, with SHA-256 checksums in `docs/data/manifest.json`.

- `Paper00-PapersMinimal-v3_077.zip` — 31 current TeX/PDF pairs, release notes, xref/build material and source integration records.
- `Paper00-ProofChainAudits-v1_83.zip` — 31 paper-level reports, additional cross-paper audits and registries.
- `Paper00-DAGAtlas-v1_223.zip` — inherited canonical graph, current v3.077 anchor map and metadata.
- `Paper00-S3StructureNetwork-v1_49.zip` — verified finite-geometry network, graph data, reproducibility scripts and SVG diagrams.

The earlier DAG archive v1.214 was around 205 MB in compressed form and therefore unsuitable as a normal Git blob. The **current** v1.223 ZIP is much smaller (about 29 MB), so this v1.2 package can include it directly. Do not confuse the current atlas with its much larger older archival edition.

**Versioning:** use the exact versioned manuscript filename when citing a paper. Source integration does not imply independent proof certification. GitHub Releases are optional for convenience; the current original archives are already linked directly from the website.
