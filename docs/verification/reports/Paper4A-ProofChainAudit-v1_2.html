1. Finite states/effects/Born evaluation — VERIFIED on the full complex finite state grammar

Source: p4:thm:density-matrix (1,846–1,935), p4:thm:born (1,973–2,013), upstream Paper II-A p2:thm:canonical-finite-state-test-evaluation (998–1,070). The current source identifies S(A) as the full positive normalized complex-linear dual, not as a projection-only valuation. This matters at dimensions one and two and rules out an invalid Gleason-only gap.

An independently checked linear-order argument fixes an effect valuation. Finite additivity and nonnegativity on [0,I] imply monotonicity; subdivision then gives rational homogeneity, and monotonicity gives real homogeneity. Scaling extends the map to the positive cone. Every Hermitian matrix is a difference of two positive matrices; the extension is well defined because any two positive decompositions satisfy X+Y'=X'+Y. For each summand M_d, matrix units reconstruct a unique trace-dual rho; positivity on rank-one projections forces rho>=0, and normalization fixes sum Tr rho=1. This is valid also for d=1,2.

For 0<=E<=I, 0<=Tr(rho E)<=Tr rho; summing blocks proves both the upper probability bound and sum_i p_i=1 for any POVM. The role of a performed apparatus test is separate. Schur's lemma also independently confirms that fixed-state invariance under all block unitaries gives only the central simplex rho_lambda=p_lambda I/d_lambda, not a uniquely selected preparation.

Exact control: A=M_2⊕C, rho_2=[[1/4,1/8],[1/8,1/4]], rho_1=1/2, E_2=I/2+X/4, E_1=3/4; the value is 11/16. This tests a nontracial state and nonprojective effect without silently restricting to a full M_3 algebra.

2. Factor-local same-type action forces CP — VERIFIED-CONDITIONAL, and the conditional is genuine

An actual affine normalized F:S(A)→S(A) is supplied, not derived, and a certified same-type SUB occurrence provides A⊗A. 3. Kraus instruments and outcome-by-outcome quotient — VERIFIED / VERIFIED-CONDITIONAL

Source: p4:thm:finite-choi-kraus-instruments (2,252–2,333) and p4:thm:v296-outcome-wise-instrument-descent (2,338–2,403). On finite direct sums, block Choi positivity gives operators K_{mu,lambda,a}:H_lambda→K_mu and block action Phi(rho)_mu=sum_{lambda,a}K rho_lambda K*. Total trace preservation is per input block: sum_{mu,a}K* K=I_{H_lambda}. A finite CP family is an instrument precisely when the aggregate map is TP; the conditional posterior is Phi_i(rho)/p_i for p_i>0.

The process descent theorem has an independent annihilator verification. If Q is the canonical state quotient to the multiplicity-blind algebra A, the map Q Psi_i factors through Q if and only if it vanishes on ker Q. By trace duality this is equivalent to Psi_i^*(A)⊂A for each outcome. The reduced outcome maps are CP because their Heisenberg representatives are restrictions of CP maps to the preserved C*-subalgebra. Surjectivity of Q gives uniqueness. Intertwining for any adaptive outcome word follows by induction, with the output label of each previous outcome selecting only the next specified setting.

4. Common-witness versus independent tensor composition — VERIFIED-CONDITIONAL

Source: p4:prop:common-witness-cooccurrence (2,452–2,480); p4:thm:gp2-product-operation-interchange (2,483–2,530); p4:thm:independent-finite-composability (2,545–2,594); p4:thm:tensor-product (2,597–2,661). These are deliberately not the same occurrence statement.

A single previously occurring witness x can have two licensed host-natural deterministic descendants F(x) and G(x) without a second independent occurrence. The canonical map x↦(F(x),G(x)) preserves their common source relation, so this does not imply a free tensor product. An independent SUB pair is a different source scope: the frozen relation slot must admit all cross-value pairs and preserve both local tests.

The commuting-product theorem can be independently tested by differentiation: exact preservation of the direct-product unitary group law makes i_A(exp(it h)) commute with i_B(exp(is k)) for every local Hermitian h,k; differentiating in t,s at zero gives [i_A(h),i_B(k)]=0, hence all local algebra images commute. A projective relation with nontrivial cocycle does not meet that exactness hypothesis.

For finite direct sums, the multiplication homomorphism mu:A⊗B→C is surjective because C is generated by the images. Its kernel is a sum of simple central pair blocks. The explicit no-deleted-pair clause (iv) makes every central product i_A(z_lambda)i_B(w_mu) nonzero, ruling out every nonzero ideal kernel. Hence mu is an isomorphism, with minimal faithful carrier ⊕_{lambda,mu} H_{A,lambda}⊗H_{B,mu}. An independent central-corner representation argument gives the same result: the two faithful commuting factors on each surviving simple pair generate M_{d_lambda d_mu}, and relation exactness retains every pair.

5. Marginal states and non-signaling — VERIFIED-CONDITIONAL

Source: block partial-trace identity (2,408–2,444) and p4:thm:nonsignaling (2,685–2,720). The joint state's local expectation is sum_{lambda,mu}Tr[rho_{lambda,mu}(E_{A,lambda}⊗I_{B,mu})], which equals the trace of the partial-traced A block against E_A. With a local CPTP Kraus family K_i on B, cyclicity under the partial trace yields

Tr_B sum_i (I_A⊗K_i)rho_AB(I_A⊗K_i*) = Tr_B[(I_A⊗sum_i K_i* K_i)rho_AB]=Tr_B rho_AB.

This is separate from the source's Heisenberg-dual proof and supplies an exact independent route. On a Bell state, an unconditioned remote projective measurement leaves rho_A=I_2/2; conditioning on outcome zero produces |0><0|. The theorem explicitly distinguishes these cases and does not claim remote conditional states are unchanged.
